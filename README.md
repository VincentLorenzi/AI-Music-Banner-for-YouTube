# AI Music Banner (Tampermonkey)

This userscript detects likely AI‑generated music in YouTube video descriptions and displays a prominent red banner above the video player when detected.

## Installation

1. Install Tampermonkey (Chrome/Edge/Firefox) or another compatible userscript manager.
2. Create a new userscript and paste the contents of `ai-music-banner.user.js` into it, or open the file with Tampermonkey's import.
3. Ensure the script is enabled and open a YouTube video page to test.

## Usage

- The script runs automatically on YouTube watch pages.
- If the description contains an AI keyword or phrase, a red banner reading `AI generated music` will appear above the video.
  
## Privacy

All detection runs locally in the browser. No description text or metadata is sent to external servers.
