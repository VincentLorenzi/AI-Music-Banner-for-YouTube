# AI Music Banner (Tampermonkey)

This userscript detects likely AI‑generated music in YouTube video descriptions and displays a prominent red banner above the video player when detected.

## Installation

1. Install Tampermonkey (Chrome/Edge/Firefox) or another compatible userscript manager.
2. Create a new userscript and paste the contents of `ai-music-banner.user.js` into it, or open the file with Tampermonkey's import.
3. Ensure the script is enabled and open a YouTube video page to test.

## Usage

- The script runs automatically on YouTube watch pages.
- If the description contains an AI keyword or phrase, a red banner reading `AI generated music` will appear above the video.
- Use the close `✕` button to dismiss the banner.
- Check the `Don't show again for this channel` checkbox before closing to remember the dismissal for that channel.
- Use the Tampermonkey menu (script commands) to toggle detection or clear dismissed channels.

## Configuration

The script stores simple state using Tampermonkey's `GM_setValue`/`GM_getValue`:

- Dismissed channels are stored under `ai_banner_dismissed_channels`.
- User keywords can be stored under `ai_banner_user_keywords` if you want to modify them manually using the Tampermonkey storage editor.
- Detection enabled/disabled is stored under `ai_banner_enabled`.

## Testing

Test manually with videos whose description contains phrases such as:

- `AI generated`
- `Generated by AI`
- `made with AI`
- `vocals generated by Mubert`
- `Produced using AIVA`

Verify that:

- The banner appears when expected.
- Dismissing behaves correctly and remembering per channel works.
- No external network requests are made for detection (check DevTools Network tab).

## Privacy

All detection runs locally in the browser. No description text or metadata is sent to external servers.
